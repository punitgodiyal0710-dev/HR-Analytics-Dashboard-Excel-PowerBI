# 📊 HR Analytics Dashboard | Excel & Power BI

An interactive HR Analytics Dashboard built using **Microsoft Excel** and **Power BI** to transform raw employee data into meaningful business insights. This project focuses on workforce analytics by tracking key HR metrics such as employee count, attrition, hiring trends, salary distribution, performance ratings, and department-wise analysis.

The dashboard was developed following an end-to-end analytics workflow, including data cleaning, KPI creation, data visualization, and dashboard design. Both Excel and Power BI versions were built to compare the capabilities of each tool while delivering interactive and business-focused reporting.

## 🎯 Project Objectives

- Analyze workforce composition and employee demographics.
- Monitor employee hiring trends over time.
- Evaluate attrition across different departments.
- Compare employee performance ratings.
- Analyze salary distribution by department.
- Build an interactive dashboard for HR decision-making.
